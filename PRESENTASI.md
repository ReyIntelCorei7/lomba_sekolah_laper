# SLIDE 2: PENDAHULUAN

## 📖 Latar Belakang

Di era digital saat ini, kehadiran sebuah sekolah di dunia maya menjadi sangat penting. Website sekolah bukan hanya sekedar tempat untuk menampilkan informasi, tetapi juga menjadi **wajah digital** yang mencerminkan kualitas dan profesionalisme institusi pendidikan.

### Permasalahan yang Kami Temukan:

1. **Keterbatasan Informasi** - Calon siswa kesulitan mendapatkan informasi lengkap tentang sekolah
2. **Proses Pendaftaran Manual** - PPDB masih dilakukan secara offline yang memakan waktu
3. **Kurangnya Eksposur** - Program keahlian, ekstrakurikuler, dan prestasi sekolah kurang dikenal luas
4. **Komunikasi Terbatas** - Tidak ada platform terpusat untuk berita dan pengumuman sekolah

### Solusi yang Kami Tawarkan:

Membangun website profil sekolah yang **modern, responsif, dan informatif** dengan fitur pendaftaran online terintegrasi.

# SLIDE 4: TEKNOLOGI YANG DIGUNAKAN

## 💻 Tech Stack

### Backend (Server-Side)
| Teknologi | Versi | Fungsi |
|-----------|-------|--------|
| **PHP** | 8.2 | Bahasa pemrograman utama |
| **Laravel** | 12 | Framework PHP untuk struktur MVC |
| **MySQL/MariaDB** | - | Database untuk menyimpan data |

### Frontend (Client-Side)
| Teknologi | Versi | Fungsi |
|-----------|-------|--------|
| **Tailwind CSS** | 4.1.18 | Framework CSS untuk styling |
| **Alpine.js** | 3.15.8 | JavaScript framework untuk interaktivitas |
| **Vite** | 7.0.7 | Build tool untuk asset bundling |

### Mengapa Laravel?

1. ✅ **Arsitektur MVC** - Kode terstruktur dan mudah maintenance
2. ✅ **Keamanan Built-in** - CSRF, XSS, SQL Injection protection
3. ✅ **Eloquent ORM** - Query database yang aman dan mudah
4. ✅ **Blade Templating** - Template engine yang powerful
5. ✅ **Komunitas Besar** - Dokumentasi lengkap, banyak tutorial

### Mengapa Tailwind CSS + Alpine.js?

1. ✅ **Utility-First CSS** - Development cepat tanpa menulis CSS custom
2. ✅ **Responsive Design** - Mudah membuat tampilan mobile-friendly
3. ✅ **Lightweight** - Alpine.js hanya ~15KB, tidak membebani loading
4. ✅ **No Build Complexity** - Tidak memerlukan setup React/Vue yang kompleks

## ❓ SESI TANYA JAWAB

### Pertanyaan yang Mungkin Ditanyakan:

**Q1: Mengapa memilih Laravel, bukan framework lain seperti CodeIgniter atau native PHP?**
> Laravel memiliki struktur MVC yang rapi, fitur keamanan built-in, dan Eloquent ORM yang memudahkan interaksi dengan database. Dokumentasinya juga sangat lengkap.

**Q2: Bagaimana cara menangani jika banyak pendaftar PPDB secara bersamaan?**
> Laravel sudah dioptimasi untuk handling multiple requests. Untuk production, bisa ditambahkan caching dengan Redis, queue system untuk proses berat, dan load balancing.

**Q3: Apakah website ini bisa di-deploy ke server hosting?**
> Ya, website ini bisa di-deploy ke shared hosting (seperti Hostinger, Niagahoster), VPS (DigitalOcean, Vultr), atau cloud platform (Railway, Vercel, AWS).

**Q4: Bagaimana proses development website ini?**
> Kami menggunakan metodologi agile dengan iterasi berkala. Tools yang digunakan: VS Code/Cursor untuk coding, Git untuk version control, Laragon untuk local development.
